# Result Page Content System (結果頁內容系統)

此系統根據問卷邏輯，定義了 8 種核心 Skin Aura 的內容輸出。所有文案皆採高端美容品牌 (Premium Beauty Clinic) 的語氣：優雅、療癒、專業且不帶批判性。

---

## Aura Type 1: Overworked Glow (疲勞發光型)
*   **Aura Color:** 冷藍紫 Aura (Cool Blue-Purple)
*   **Keywords:** 疲勞・低電量・缺水・都市感
*   **Quote (核心金句):** 「你需要的不是更多刺激，而是真正恢復皮膚能量。」(Your glow starts with recovery.)
*   **Personality Description (性格描述):** 外表看起來依然精緻，但其實正處於長期低能量狀態。你習慣了高輸出的生活節奏，對自己要求極高，往往在不經意間消耗了皮膚最底層的水分與活力。
*   **Skin Needs (肌膚需求):** ✦ 深層補水 (Deep Hydration) ✦ 能量恢復 (Skin Recovery) ✦ 舒緩緊繃 (Nervous System Reset)
*   **Recommended Ritual (推薦護理方向):** 建議從重建肌底循環開始。選擇強調修復與注水療程，為過勞的細胞重新充電。(註：此處需與診所實際療程如「水光針/深層保濕護理」對應)
